# ⚡ EnerVision – AI Energy Consumption Prediction System

## Description

EnerVision is an AI-powered energy consumption prediction system designed to analyze household energy usage, identify consumption patterns, and predict future energy consumption. The system uses machine learning and deep learning models along with an interactive Streamlit dashboard to provide energy analysis, visualization, and prediction.

## Features

* Upload and analyze energy consumption datasets
* Energy consumption prediction
* Manual energy consumption prediction
* Average consumption analysis
* Maximum and minimum consumption analysis
* Peak consumption time detection
* Consumption trend visualization
* Hourly energy consumption analysis
* Machine learning and deep learning model comparison
* Interactive Streamlit dashboard
* CSV-based data processing
* Energy usage insights for better energy management
